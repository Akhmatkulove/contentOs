# 0006. Референсы из съёмки и пул креатора

Статус: принято, 2026-10-08

## Контекст

Арт-директор на странице Create new shoot прикрепляет к съёмке референсы из пула (Browse reference bank) и хочет добавлять новые прямо там, как бренд в создании продукта (ADR 0003). Креаторы снимают по референсам арт-директора, поэтому должны видеть их в пуле. До этого креатор видел только свои референсы (ADR 0004).

## Решения

### Новые референсы сохраняются в пул сразу

Add reference на странице съёмки открывает ту же модалку, что и в пуле, и сохраняет референс так же: по Add reference в модалке файлы загружаются, затем `POST /api/references`; при ошибке модалка остаётся открытой. Сохранённый референс сразу появляется в пуле и отмечен для съёмки. Product выбирается из отмеченных продуктов съёмки, Creator — арт-директор, Shoot пока выключен. Browse reference bank заменяет весь список референсов съёмки, новые там уже есть.

Если съёмку так и не создали или референс сняли с неё, он остаётся в пуле.

Изначально (2026-10-08) новые референсы были черновиками в памяти страницы и сохранялись в пул только по Create shoot; заменено 2026-10-20: референс не должен теряться, если съёмку не создали.

### Креатор видит пул своих арт-директоров

Креатор видит всё, что видят арт-директора, в чьих командах он состоит (`art_director_creators`, ADR 0002): референсы, созданные ими, и референсы продуктов, где на них назначен deliverable (ADR 0004), плюс свои. Это касается списка, фильтров и избранного (`_visible` в `app.references.service`).

Доступ выводится из связок: снятие креатора из команды в админке сразу убирает пул арт-директора. Свои референсы креатор по-прежнему создаёт без продукта или с продуктом, где на него самого назначен deliverable.

## Не входит в эту итерацию

API съёмок, поле Shoot в модалке, фильтр пула по съёмкам, Add reference на мобильном (в Figma его нет).
