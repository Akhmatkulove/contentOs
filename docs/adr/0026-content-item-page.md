# 0026. Страница контента

Статус: принято, 2026-10-20

## Контекст

С карточки на странице Content (ADR 0025) нужно попадать на страницу самого контента: Figma «SCREEN:c_item Content / Walking transition» — сцена с файлом и лентой миниатюр, комментарии, детали, референс и версии.

## Решения

- Страница — отправленный бренду deliverable целиком: `GET /api/content/{deliverable_id}`. Его файлы (строки `content_items`) — материалы страницы, по порядку отправки. Карточка открывает страницу на своём файле (`?file=<content item id>`). Видят страницу те же, кто видит файлы на Content, и только видимые им файлы; чужое — 404.
- Сцена показывает файл с обрезкой (cover), у видео — кнопка Play. Сцена и «+N» открывают просмотрщик со всеми файлами в их пропорциях.
- Комментарии к deliverable (`content_comments`) пишут только бренд продукта и арт-директор съёмки; читают все, кто видит страницу. Вкладки Activity нет. В меню «…» комментария: свой можно удалить (`DELETE /api/content/{id}/comments/{comment_id}`, только автор), чужой — Report comment, ведёт в Telegram поддержки в новой вкладке (ссылка пока заглушка). Длинная лента прокручивается внутри карточки.
- О комментарии уведомляются все, кого касается контент (бренд, арт-директор съёмки, авторы файлов), кроме написавшего: тип `content_commented`. Пока уведомление не прочитано, следующие комментарии к тому же deliverable прибавляются к нему.
- Approve — только бренд, весь deliverable разом: всем его строкам `status = approved` и `approved_at`. Повторно ничего не меняет. Арт-директор съёмки и авторы получают `content_approved`. Кнопка — в шапке справа от Copy link (на мобильном — строкой под ней); одобрение показывается в ленте комментариев там, где случилось, и статусом у заголовка.
- Избранное — только у бренда (`content_favorites`, по deliverable). На странице Content у бренда вкладка Favorites (`scope=favorites`): все файлы deliverables в избранном; у остальных её нет, `counts.favorites` — 0. Download и Copy link пока без действия.
- В деталях нет Edit и Resolution. Съёмку видят только её арт-директор и креаторы его команды, как на Content; версии (отправленные, с размером и решением) — только арт-директор съёмки.
- Референсы: сначала референсы deliverable съёмки, затем референсы продукта, новые первыми (в том числе добавленные после отправки). Видят все, кому видна страница, бренд тоже. В сайдбаре не больше трёх; View all — только если их больше, ведёт на вкладку References продукта. Команда открывает страницу референса, бренд — файлы в просмотрщике или ссылку.
- Previous / Next — соседние отправленные deliverables в порядке Content по умолчанию (новые первыми), без учёта фильтров списка.
- Уведомления о контенте (`content_sent`, `content_commented`, `content_approved`) открывают эту страницу.

## Не входит в эту итерацию

Скачивание и ссылка, редактирование комментариев, отзыв одобрения.
