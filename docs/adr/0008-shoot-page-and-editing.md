# 0008. Страница съёмки и её редактирование

Статус: принято, 2026-10-08

## Контекст

У съёмки появилась своя страница: шапка (название, дата, адрес, статус, Edit shoot) и вкладки Overview, Products, Tasks. Редактировать съёмку может только тот, кто её создал. Tasks — это deliverables съёмки: у каждого исполнители из команды, и эти же задачи позже придут к ним в My tasks (ADR 0007).

## Решения

### `GET /api/shoots/{id}` — всё одним запросом

Автору и команде (`_visible` из ADR 0007), остальным `404`, как у несуществующей. В ответе: поля съёмки, статус (выводится, ADR 0007), арт-директор, креаторы и мобилограф, продукты с первым фото и счётчиками deliverables по статусам, референсы (`ReferenceResponse`), deliverables (продукт, исполнители, id референсов, дата, статус) и `can_edit` — пользователь автор съёмки.

Поиск, фильтры и сортировка вкладок работают в браузере по этому ответу: съёмка небольшая, отдельные эндпоинты не нужны. Вкладка — в URL (`?tab=tasks`), фильтры вкладок — нет.

### `PUT /api/shoots/{id}` — форма целиком

Только автор (`403` не арт-директору, `404` чужому). Тело — как у `POST /api/shoots`. Команда, продукты и референсы записываются заново. Deliverables: с `id` — обновляются и сохраняют id (на нём будут задачи и загрузки), без `id` — создаются, не перечисленные — удаляются; чужой `id` — `422`.

Проверки те же, что при создании, но уже стоящие в съёмке креаторы, продукты и референсы проходят без них: связку с креатором или назначение на продукт могли снять после создания, и это не должно мешать сохранить остальное.

### Фронт

- Edit shoot ведёт на `/shoots/:id/edit` — та же форма, что Create shoot, заполненная сохранённой съёмкой. После сохранения (и после создания) открывается страница съёмки.
- View product в карточках продуктов видит только автор: креаторы продуктов не видят (ADR 0004).
- Обложки на Overview — первые фото продуктов съёмки.

## Не входит в эту итерацию

Вкладки Needs review, Approved, References, Files, Team, Notes и меню «…»; Add cover, Shoot description, Goals, Files, Add member (полей нет); колонка Latest upload и действия строки в Tasks; фильтры на мобильном.
