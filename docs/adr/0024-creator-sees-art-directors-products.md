# 0024. Креатор видит продукты своих арт-директоров

Статус: принято, 2026-10-20

## Контекст

Креатор снимает продукты, которые бренд отдал его арт-директору, но в разделе Products у него было пусто: ADR 0004 оставил креатору пустой список «до съёмок». Пул референсов уже работает по правилу команды (ADR 0006): креатор видит всё, что видят арт-директора, в чьих командах он состоит.

## Решения

### Продукты — по тому же правилу, что пул

Креатор видит продукт, если хотя бы один deliverable продукта назначен на арт-директора из его команд (`art_director_creators`). Правило одно для списка, фильтров, `GET /api/products/options` и страницы продукта (`_visible` в `app.products.service`). Отдельной привязки к съёмкам нет: креатор видит продукты арт-директора ещё до того, как их запланировали.

- На странице продукта креатор видит deliverables своих арт-директоров, как арт-директор — только свои. Редактировать продукт он не может (`can_edit: false`).
- Доступ выводится из связок: снятие креатора из команды или арт-директора с deliverables сразу убирает продукты. Участник съёмки, которого убрали из команды, по ссылке View product получит 404.

### Свои референсы с продуктом

Продукт в своём референсе креатор выбирает из тех, что видит: продуктов своих арт-директоров (раньше — где deliverable на нём самом, то есть ни одного). Такой референс видят все, кто видит референсы продукта: бренд, назначенные арт-директора и их креаторы.

### Интерфейс

На вкладке Products съёмки ссылку View product видят все участники, не только автор съёмки.

## Не входит в эту итерацию

Продукты только по съёмкам креатора, вкладка продукта с его задачами.
