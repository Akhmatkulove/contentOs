# 0025. Страница Content

Статус: принято, 2026-10-20

## Контекст

Арт-директор одобряет работу исполнителей и отправляет deliverable бренду (ADR 0015). Отправленное нужно где-то видеть: Figma «SCREEN:c_list Content» — сетка файлов с названием deliverable, продуктом, съёмкой и статусом.

## Решения

- Send to brand кладёт на страницу каждый файл одобренной (выбранной, ADR 0016) версии каждого текущего исполнителя: строка `content_items` (файл, deliverable, автор, порядок, статус, время отправки). Хранится отдельно, а не выводится из версий: у файла будет свой статус от бренда.
- Название deliverable копируется в момент отправки: форма съёмки может его поменять, а отправленное бренду остаётся как было. Продукт берётся через deliverable: у сохранённого deliverable форма менять его не даёт.
- Статус начинается с `new`. `approved` поставит бренд, когда появится его проверка (следующий шаг).
- Кто видит (вкладка All content):
  - бренд — контент своих продуктов;
  - арт-директор — контент своих съёмок и продуктов, где на него назначен deliverable бренда (ADR 0004);
  - креатор — контент съёмок своих арт-директоров (как пул, ADR 0006) и снятое им самим.
- My content: креатору — снятое им, арт-директору — из его съёмок, бренду — то же, что All content.
- Съёмку (название, фильтр, поиск по ней) видят только её арт-директор и креаторы его команды. Бренду она не отдаётся.
- Поиск — по deliverable, продукту, креатору и (кому видно) съёмке; фильтры Product, Shoot, Creator, Status; сортировка по времени отправки или названию.
- Бренд получает уведомление в колокольчике (ADR 0020), тип `content_sent`: «Your order is ready: Close-up for Black Abaya (3 files)». Одно на каждый отправленный deliverable, без склейки; в строке — арт-директор, продукт, deliverable (`notifications.deliverable_id`, CASCADE) и число файлов. Клик открывает Content с фильтром по продукту. Отправленным до миграции уведомления не создаются.
- Миграция переносит уже отправленные deliverables; время отправки у них — последнее решение по deliverable.
- Если deliverable убрать из съёмки, его контент удаляется вместе с ним (каскад).

## Не входит в эту итерацию

Проверка контента брендом, фильтр типа медиа (All media), вкладки Recent, Favorites и Trash, выбор чекбоксами и меню «…» карточки, место в хранилище.
