# 0012. Страница задачи и версии готового контента

Статус: принято, 2026-10-14

## Контекст

Из My tasks (ADR 0011) кнопка View должна открывать саму задачу: продукт, детали и готовый контент, который загружает исполнитель. Арт-директор видит ту же страницу, но без загрузки. Контент сдаётся версиями: первая загрузка — V1, дальше новые версии, которые можно назвать по-своему.

## Решения

### Версии и черновик

- `task_versions`: версия deliverable съёмки — номер (1, 2, … внутри deliverable, уникален), необязательное название (до 100 символов), автор, время создания и `submitted_at`. `task_version_files`: файлы версии по порядку; файл принадлежит одной версии.
- Версия без `submitted_at` — черновик. У задачи он один, общий для её исполнителей. Первые загруженные файлы создают черновик V1, следующие добавляются в него, пока исполнитель не нажмёт Submit for review.
- Submit for review отправляет черновик: ставит `submitted_at`, сохраняет название и переводит deliverable в `needs_review` (как задумано в ADR 0009). После этого следующие файлы начинают черновик V2; поле Version title появляется, когда отправлена хотя бы одна версия.
- Файлы убираются только из черновика; черновик без файлов удаляется. Отправленные версии не меняются: это история того, что видел арт-директор. Файл удаляется сразу (строка до commit, объект в хранилище после).
- Арт-директор черновик не видит.
- У файлов появилось имя (`files.name`): его присылает браузер при загрузке, используется только для показа.

### API

- `GET /api/tasks/{id}` — строка My tasks плюс `versions` (отправленные, новые первыми), `draft` (только исполнителям) и `can_upload`. Кто не видит задачу в My tasks, получает 404.
- `POST /api/tasks/{id}/draft/files` `{file_ids}` — файлы из `POST /api/uploads` в черновик; только исполнитель (арт-директору 403).
- `PATCH /api/tasks/{id}/draft` `{title}` — Save draft: название черновика без отправки; без черновика 409.
- `POST /api/tasks/{id}/draft/submit` `{title}` — Submit for review; без черновика 409.
- `DELETE /api/tasks/{id}/draft/files/{file_id}`.

### Интерфейс

- View в My tasks ведёт на `/tasks/:id`; Review у арт-директора пока ведёт на вкладку Needs review съёмки.
- Отправленные версии — раскрывающиеся карточки, последняя раскрыта; на ней статус задачи: needs review → «On review», needs changes, approved.
- Под ними у исполнителя: Version title (после V1), зона загрузки, файлы черновика и кнопки Save draft и Submit for review под карточкой. Файлы попадают в черновик сразу после загрузки, Save draft сохраняет название.
- Edit task — арт-директору, ведёт в форму съёмки.

## Не входит в эту итерацию

Блок референсов под Ready content, формат задачи («Reel», «15–30s»), экран проверки и комментарии к версиям.
