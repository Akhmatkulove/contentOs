# 0010. Заметки съёмки

Статус: принято, 2026-10-08

## Контекст

Вкладка Notes на странице съёмки: заметки команды (напоминания, креативное направление, фидбек). По умолчанию заметок нет; New note открывает модалку, «…» у заметки — Edit, Pin, Delete.

## Решения

```
shoot_notes            id, shoot_id, author_id, title, type, visibility, body, pinned, created_at
shoot_note_assignees   note_id, user_id, position
```

- `type`: `general`, `creative`, `logistics`, `feedback`, `post_production`. `visibility`: `internal` — вся команда съёмки; `private` — автор, отмеченные в Assign to и арт-директор съёмки. Варианты в Figma не раскрыты, выбраны так.
- Текст — обычный текст; каждая непустая строка показывается пунктом списка (как в Figma).
- Писать может любой участник съёмки (арт-директор, креаторы, мобилографы). Менять, закреплять и удалять — автор заметки и арт-директор съёмки; остальным `404`, как у несуществующей. Assign to — только из команды съёмки, иначе `422`.
- API: `GET/POST /api/shoots/{id}/notes`, `PUT/PATCH/DELETE /api/shoots/{id}/notes/{note_id}` (`PATCH` — только `pinned`). Список: закреплённые первыми, затем новые.
- На фронте заметки грузятся при открытии вкладки; поиск (заголовок, текст, автор) и фильтр All notes / Pinned / по типу — в браузере.

## Не входит в эту итерацию

Уведомления отмеченным, история правок, подтверждение удаления, форматирование текста, фильтры на мобильном.
