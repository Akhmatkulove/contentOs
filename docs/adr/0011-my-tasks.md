# 0011. Страница My tasks

Статус: принято, 2026-10-09

## Контекст

Deliverables съёмки назначаются на людей из её команды (ADR 0007). Исполнитель должен видеть свои задачи в одном списке по всем съёмкам, а арт-директор — всё, что снимается на его съёмках, чтобы проверять загрузки.

## Решения

### Что считается задачей

Задача — deliverable съёмки (`shoot_deliverables`), отдельной таблицы нет:

- креатор (и мобилограф) видит deliverables, где он исполнитель (`shoot_deliverable_assignees`);
- арт-директор видит все deliverables своих съёмок, колонка Assignee показывает исполнителей;
- бренду страница закрыта (`403`, маршрут только для команды).

Deliverables продукта (ADR 0004) в My tasks не попадают.

### `GET /api/tasks`

`search` (deliverable, продукт, съёмка, исполнитель), `status`, `shoot_id`, `product_id`, `assignee_id`, `sort`, страницы. `counts` — число задач каждого статуса под поиском и фильтрами: из них вкладки. Строка отдаёт съёмку, продукт с первым фото и SKU, исполнителей и первые три референса с общим числом (`references_total`).

`sort`:

- `priority` (по умолчанию) — сначала то, что ждёт действия пользователя, затем по сроку. Арт-директору: needs review → needs changes → in progress → to shoot → approved. Креатору: needs changes → to shoot → in progress → needs review → approved;
- `due_date` — ближайший срок первым, без срока в конце;
- `name_asc`.

`GET /api/tasks/filters` — съёмки, продукты и исполнители, которые встречаются в задачах пользователя.

### Интерфейс

- Вкладки арт-директора: All, Needs review, Needs changes, To shoot, Approved; креатора: All, To shoot, Needs changes, Approved. Фильтры арт-директора — съёмка и исполнитель, креатора — продукт. Вкладка, поиск, фильтры, сортировка и страница живут в URL.
- Action: у креатора всегда View, у арт-директора Review для needs review и needs changes, иначе View. View открывает съёмку на вкладке Tasks, Review — на вкладке Needs review, пока нет экрана проверки.
- Add deliverable (арт-директору) ведёт на страницу Shoots: deliverable добавляется в съёмку.

## Не входит в эту итерацию

Загрузки контента: превью задачи, формат («Reel · 15–30s») и Latest upload — заглушки. Чекбоксы и массовые действия, меню «…» строки, фильтры на мобильном, счётчик задач в навигации.
